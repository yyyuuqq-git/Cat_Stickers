# 🐾 고양이 칭찬스티커 이미지 안내

사용자님께서 추후 스티커 이미지를 업로드하실 수 있도록 준비된 폴더입니다.

## 📁 권장 파일명 및 매핑
기본 고양이 테마에 매핑된 5종 스티커 파일명입니다:
1. `cat1.png` - 치즈냥이 🐱 (치즈태비)
2. `cat2.png` - 삼색이 😸 (삼색고양이)
3. `cat3.png` - 턱시도냥 🐈‍⬛ (턱시도고양이)
4. `cat4.png` - 하얀냥이 🤍 (순백의 고양이)
5. `cat5.png` - 핑크냥발 🐾 (분홍 젤리 발바닥)

## 💡 참고 사항
- **자동 백업 그래픽 (SVG)**: 이미지를 업로드하기 전이거나 이미지 파일이 누락된 경우, 브라우저에서 자동으로 귀여운 **고양이 벡터 일러스트(SVG)** 가 표시되므로 오류 없이 예쁘게 동작합니다.
- **권장 규격**: 1:1 정사각형 비율 (예: 256x256 또는 512x512), 투명 배경(PNG)을 권장합니다.
- 이미지를 이 폴더에 넣으시면 새로고침 시 즉시 실제 이미지로 전환되어 표시됩니다.
